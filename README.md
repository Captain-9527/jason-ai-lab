## 使用约定

- 笔记使用 Markdown 编写，并尽量记录日期、结论、示例和参考资料。
- 每个项目应包含独立的 README、依赖说明和运行方法。
- API Key、令牌、账号信息、私有数据及模型权重不得提交到仓库。
- 环境变量通过 `.env` 管理，并提供不含敏感值的 `.env.example`。
